# Student Performance Prediction System

A classroom prototype that flags students who may be at risk of failing the final
Mathematics grade, built for a Data Mining laboratory.

## Problem
Academic risk is often noticed only after poor results. This prototype explores
early identification using available student indicators (study time, absences,
failures, G1, G2, etc.).

## Dataset
UCI Machine Learning Repository, *Student Performance* (ID 320):
https://archive.ics.uci.edu/dataset/320/student+performance

**Dataset note:** the original UCI release has a Mathematics file (395 rows) and a
Portuguese-language file (649 rows). Check the row count printed by `train_model.py`
to confirm which records were retrieved.

## Prediction target
`G3 < 10` → **AT RISK** (1); `G3 >= 10` → **NOT AT RISK** (0).
`G3` is the target only and is never used as an input feature.

## Technologies
Python 3.10+, pandas, scikit-learn (Random Forest), joblib, Streamlit, Git/GitHub.

## Installation and run
```bash
pip install -r requirements.txt
python train_model.py      # downloads data, trains model, creates student_model.pkl
streamlit run app.py       # opens http://localhost:8501
```
In the app, download the sample input CSV, upload it, and view/download predictions.

## Model results
See `evaluation_results.txt` (generated by `train_model.py`).

## Limitations
- Trained on one Portuguese secondary-school dataset; may not generalize to other
  institutions or populations.
- Including G1 and G2 makes prediction easier but later in the academic cycle.
- Predictions are not diagnoses and must not be the sole basis for real student decisions.
